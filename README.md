# 《风栖群岛》Fengqi Isles · V2「云海环游与天空之城」

3D 手绘水彩绘本风的空岛世界 demo。可以步行、滑翔，乘坐云轨列车「风栖号」环游六座主题空岛，乘天空支线或飞艇「风帆号」前往可探索的天空之城艾瑟兰，并在云海与岛屿之间遇见云鲸、云鳐和夜里升起的天灯。

开局所在的风栖主岛上：南边是云轨车站「风栖站」，西边是天空支线「风栖西站」，东北岸的空港停着飞艇「风帆号」（航线：风栖主岛 → 艾瑟兰 → 云港 → 风栖主岛；无人乘坐时停在主岛，在其他空港可按 E 呼叫）。

在线版：<https://taoyanzhu1024-bot.github.io/fengqi-islands/>（更新后请 Ctrl+F5 强制刷新）

## 运行

浏览器不允许 `file://` 直接加载 ES 模块，需要起一个本地静态服务器：

```bash
cd fengqi-islands
python3 -m http.server 8080      # 或：npx serve .
```

然后打开 <http://localhost:8080>。Three.js（r170）已放在 `lib/` 里，不需要联网，也不需要构建。

URL 参数：`?nointro` 跳过开场镜头；`?t=dawn|noon|dusk|night` 指定时间。

## 世界内容

- **风栖主岛**（出生点）：金叶古树、童话小屋、水井、晾衣绳、菜园与稻草人、风车、干草车、小木桥、彩旗、村民；风栖站与天空支线西站、观景台、乘风台
- **花海岛**：色带花田、凉亭、三座风车、樱花树、花拱门、花车、花摊、蜂箱、花农
- **云港岛**：钟楼广场集市（五个小摊与彩旗）、旅客、三条栈桥与停泊飞艇、**风帆号空港**
- **森林岛**：参天巨树、两座树屋、伐木小屋（炊烟）、精灵蘑菇圈、林间灯、萤火虫
- **灯塔岛**：旋转光束的灯塔、守塔人小院（花箱、晾衣绳、水井、小划艇）
- **雪鸣岛**：雪峰、雪松、冰晶、风铃神社、石灯笼小路、经幡、雪屋与炊烟、雪人、雪橇、冰湖
- **天空之城 · 艾瑟兰**（可到达）：中央广场与三层喷泉、云轨中央车站与钟楼、商业街、环形街区、空中花园与远眺台、天空王庭（尖塔、拱廊、廊桥）、王庭乘风台、东北岸空港；42 名居民按昼夜作息活动
- **交通**
  - 云轨环线（约 6.3 km，6 站），轨道在列车前方从云中逐段升起
  - 天空支线：风栖西站 ⇄ 艾瑟兰中央车站（往返运行）
  - 飞艇「风帆号」：云港岛 ⇄ 艾瑟兰（约 5 km 闭合航线，单程约 100 秒）；无人乘坐时会在两港之间定时往返，也可以在空港按 E 呼叫
- **云鲸**：在云海中巡游，会翻滚、跃出云海、下潜、喷气；乘车或乘飞艇时会游到窗边并排同行；夜晚身上的光点亮起
- **昼夜**：48 分钟一昼夜，太阳弧线运动，星星、月亮、夜灯

## 关于模型

所有模型（列车、飞艇、云鲸、建筑、角色、道具）都是代码程序化建模，不是 Blender / GLB 资产。详见 `docs/ASSETS.md`。

## 性能说明

- 静态道具按材质合批；天空之城按 56 m 分块合批，并按距离在细节块与简化体块之间切换（LOD）。
- 居民、草叶、花朵均为实例化渲染；远离时停止更新。
- 帧率低于约 38 fps 时自动降低渲染分辨率；“高”画质提高阴影分辨率与 LOD 距离。
- 本仓库的自动化测试运行在无 GPU 的软件渲染环境中，无法给出真实显卡上的帧率。
