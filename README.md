# 《风栖群岛》Fengqi Isles · 网页 3D 世界展示 demo

3D 手绘水彩绘本风的天空之城 / 空岛世界探索 demo。玩家可以步行、滑翔、乘坐云上列车环游六座主题空岛，并在观景点用电影镜头眺望远方的天空之城。

## 运行

浏览器不允许 `file://` 直接加载 ES 模块，需要起一个本地静态服务器（任选其一）：

```bash
cd fengqi-islands
python3 -m http.server 8080      # 或：npx serve .
```

然后打开 <http://localhost:8080>。Three.js（r170）已放在 `lib/` 里，不需要联网，也不需要构建。

| 按键 | 作用 |
| --- | --- |
| WASD / 方向键 | 移动 |

| H | 隐藏按键提示 |

## 世界内容

- **风栖主岛**（出生点）：金叶古树、童话小屋、风车、石板路、溪流与瀑布、风栖站、观景台（E 眺望天空之城）、乘风台（E 起跳滑翔）
- **花海岛**：色带花田、凉亭、三座彩色风车、樱花树、飘落花瓣
- **云港岛**：钟楼广场、环形建筑群、三条空港栈桥与停泊飞艇，另有飞艇在群岛间往来
- **森林岛**：参天巨树、发光蘑菇与植物、萤火虫、溪流瀑布
- **灯塔岛**：高崖灯塔（旋转光束）、守塔人小屋、远眺点
- **雪鸣岛**：海拔最高、冷色调，雪峰、雪松、冰晶、风铃神社、飘雪
- **风铃屿 / 望云屿 / 小灯屿**：主岛北侧的滑翔小浮岛，附近有白色上升气流
- **天空之城 · 艾瑟兰**：约 4 km 外的远景地标（不可到达）
- 约 70 座远景浮岛、云海、空中云朵、飞鸟群

云轨环线全长约 6.3 km，串起六座车站。列车最高速约 86 km/h，进出站会缓慢加减速，每站停靠约 12 秒。

## 代码结构

```
index.html            页面与 HUD 结构（importmap 指向 lib/three.module.min.js）
css/style.css         极简 HUD 样式
js/main.js            入口：渲染器、灯光、主循环、交互与列车/镜头逻辑
js/config.js          调色板、岛屿配置、路线、上升气流、天空之城位置
js/core/              噪声、数学工具、水彩材质、几何合批、物理查询、键盘输入
js/world/terrain.js   Island：不规则岛缘、高度场（渲染与碰撞共用）、分层岩体
js/world/props.js     树、金叶古树、房屋、风车、灯塔、凉亭、飞艇等道具
js/world/vegetation.js 实例化草叶（风吹 + 角色踩踏）与野花
js/world/islands/*.js 各主题岛的地形塑形、配色与布置
js/world/railway.js   环线规划、金色云轨、车站、列车状态机
js/world/sky.js       天空穹顶、云海、云朵广告牌
js/world/background.js 远景浮岛、天空之城、飞鸟
js/world/particles.js 环境粒子、萤火、上升气流、蒸汽、瀑布
js/player/            角色模型与控制器（步行 / 跳跃 / 滑翔 / 乘车 / 坠落重生）
js/camera/rig.js      第三人称跟随、列车四视角、电影镜头脚本
js/post/watercolor.js 水彩后处理：湿纸扭曲、颜料晕染、深度描边、纸纹、暗角
js/ui/hud.js          区域名、提示、列车信息、小地图
```

## 性能说明

- 每座岛的静态道具合并成少量网格（按材质分类、顶点色着色），整帧约 170 个 draw call。
- 草和花在相机远离岛屿时隐藏；远景浮岛合并为 3 个网格。
- 帧率低于约 38 fps 时会自动降低渲染分辨率，帧率回升后再恢复。
- 阴影只覆盖玩家附近约 150 m 的范围。
