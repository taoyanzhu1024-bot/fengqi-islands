# 音频说明

## 素材来源与许可

本版本**没有使用任何外部音频文件**。所有声音都由 `js/audio/audio.js` 在浏览器里用 Web Audio API 实时合成，属于项目自有内容，无第三方许可问题。

这些合成音色是**占位音频**：能提供完整的声音反馈，但质感不等同于正式录音或作曲。后续如需替换为正式素材，请把文件放进 `assets/audio/`，并在本文件登记来源与许可证。

## 通道

| 通道 | 内容 |
| --- | --- |
| 主音量 | 总输出（经过压缩器） |
| 背景音乐 | 生成式五声音阶琶音 + 铺底和弦 + 低音，按岛屿和昼夜换调、换速度、换音色（雪鸣岛与夜晚为钟琴、森林为柔和正弦、天空之城偶有竖琴式琶音）；乘车时加轻柔沙锤节拍 |
| 环境音 | 高空风、阵风、草叶摩擦、瀑布、雪地风、鸟鸣、风铃、虫鸣、云鲸鸣叫；城中人声、崖边云浪、花海蜂鸣；各岛生灵（见下表）；钟楼整点报时 |
| 音效 | 脚步（草地/石板/木板/雪）、跳跃、落地、滑翔展开/收起、上升气流、交互、拾取、界面点击（设置面板开合、时间按钮、H/T/C 键）；列车汽笛、车轮咔哒、低频滚动、制动、到站铃、车门、云轨形成；飞艇汽笛、螺旋桨、船体吱呀、缆绳风声 |

列车声走单独的低通滤波：在车厢内视角时更闷、更轻，在外部视角时更亮。车轮咔哒的间隔随车速变化，低频滚动声的音量随车速变化。

## 各岛环境点缀

| 地点 | 白天 | 夜晚 |
| --- | --- | --- |
| 风栖主岛 | 鸟鸣、风铃、清晨 6 点鸡鸣、整点钟声（较轻） | 蛙鸣、偶尔的猫头鹰、虫鸣 |
| 花海岛 | 鸟鸣、蜂鸣、清晨鸡鸣 | 蛙鸣 |
| 云港 | 海鸥、远处人声、崖边云浪、整点钟声 | 云浪 |
| 森林岛 | 鸟鸣、布谷鸟、啄木鸟、虫鸣 | 猫头鹰、更密的虫鸣 |
| 灯塔岛 | 海鸥、较强的崖边云浪、雾笛 | 云浪、更响的雾笛 |
| 雪鸣岛 | 雪地风、风铃 | 雪地风、风铃 |
| 天空之城艾瑟兰 | 城中人声、鸽子、整点钟声（先奏四音前奏） | 稀疏人声、钟声 |
| 飞艇「风帆号」上 | 螺旋桨、船体吱呀、缆绳风声 | 同左 |

脚步声每一步都有轻微的音高和音量随机，石板、木板、雪地、草地各有两层声音。整点钟声只在时间自然走到整点时响起，在设置里切换时间不会触发。

所有新增声音同样是合成的**占位音频**。

## 浏览器自动播放

- 页面打开时不创建 `AudioContext`。第一次点击、按键或触摸时才创建并 `resume()`。
- 右下角「设置」面板有声音开关和四个音量滑块，设置保存在 `localStorage`。
- 页面切到后台时主音量淡出，返回时淡入。
- 浏览器不支持 Web Audio 时，设置面板会显示提示，游戏照常运行。
