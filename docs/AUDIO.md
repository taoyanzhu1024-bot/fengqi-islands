# 音频说明

## 素材来源与许可

本版本**没有使用任何外部音频文件**。所有声音都由 `js/audio/audio.js` 在浏览器里用 Web Audio API 实时合成，属于项目自有内容，无第三方许可问题。

这些合成音色是**占位音频**：能提供完整的声音反馈，但质感不等同于正式录音或作曲。后续如需替换为正式素材，请把文件放进 `assets/audio/`，并在本文件登记来源与许可证。

## 通道

| 通道 | 内容 |
| --- | --- |
| 主音量 | 总输出（经过压缩器） |
| 背景音乐 | 生成式五声音阶琶音 + 铺底和弦，按岛屿和昼夜换调、换速度 |
| 环境音 | 高空风、阵风、草叶摩擦、瀑布、雪地风、鸟鸣、风铃、虫鸣、云鲸鸣叫 |
| 音效 | 脚步（草地/石板/木板/雪）、跳跃、落地、滑翔展开/收起、上升气流、交互、拾取；列车汽笛、车轮咔哒、低频滚动、制动、到站铃、车门、云轨形成；飞艇螺旋桨 |

列车声走单独的低通滤波：在车厢内视角时更闷、更轻，在外部视角时更亮。车轮咔哒的间隔随车速变化，低频滚动声的音量随车速变化。

## 浏览器自动播放

- 页面打开时不创建 `AudioContext`。第一次点击、按键或触摸时才创建并 `resume()`。
- 右下角「设置」面板有声音开关和四个音量滑块，设置保存在 `localStorage`。
- 页面切到后台时主音量淡出，返回时淡入。
- 浏览器不支持 Web Audio 时，设置面板会显示提示，游戏照常运行。
